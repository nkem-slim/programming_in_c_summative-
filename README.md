# Programming in C - Guide for project
## Nkem Vincent Nweke

This repository contains all 5 projects submitted for the C programming summative: a smart parking system (Arduino + PCB), a Linux backup/recovery script, a library inventory manager, a unit conversion toolkit, and a multi-threaded file processor.

---

## 1. Smart Parking System (Arduino + EasyEDA PCB)

**File:** `smart_parking_system.ino`

Simulated in Tinkercad, with a matching schematic and PCB layout designed in EasyEDA (PCB project files/screenshots included separately in the submission document).

No build step needed to test in Tinkercad — open the sketch in the Arduino IDE or paste it into a Tinkercad Arduino Uno project's code editor and run the simulation.

Monitors 4 parking spaces using LEDs on pins 2–5, with entry/exit push buttons on pins 6 and 7. Parking data is stored in a dynamically allocated array of `ParkingSpace` structs, accessed via pointers, with non-blocking status updates driven by `millis()`.

## 2. Linux File Backup and Recovery Manager

**File:** `file_backup_recovery.sh`

Run it directly:
```bash
chmod +x file_backup_recovery.sh
./file_backup_recovery.sh
```

Follow the on-screen menu to create a backup, restore one, view history, delete a backup, or view/clear the activity log.

## 3. Library Book Inventory Management System

**File:** `library_book_inventory_management_system.c`

Compile and run:
```bash
gcc library_book_inventory_management_system.c -o library_inventory
./library_inventory
```

Records are saved to and loaded from `books.txt` automatically.

## 4. Unit Conversion Toolkit (Function Pointers + Callbacks)

**File:** `smart_calculator_with_function_pointers.c`

Compile and run (needs the math library for the precision callback):
```bash
gcc smart_calculator_with_function_pointers.c -o unit_converter -lm
./unit_converter
```

Conversion history is saved to and loaded from `history.txt` automatically.

---

## 5. Multi-threaded File Processing System

**File:** `multi_threaded_file_processing_system.c`

Compile and run:
```bash
gcc multi_threaded_file_processing_system.c -lpthread
./a.out example.txt history.txt books.txt
```

Each filename passed in gets its own thread. For a quick test without creating new files, you can reuse output already generated by the other projects in this repo:

- `example.txt` — a small sample text file included for testing
- `history.txt` — generated by the Unit Conversion Toolkit (Project 4)
- `books.txt` — generated by the Library Inventory System (Project 3)

Each thread analyzes its file's line, word, and character counts and writes the results to a matching `<filename>_result.txt` file — for example, `example.txt_result.txt`.

## Notes

- All C programs use dynamic memory (`malloc`/`realloc`/`free`) and free everything before exiting.
- The backup script and file processor both handle missing/invalid files gracefully without crashing.
